# SeaCreatures: Create 3D models in the Shared Space

Use volumes to add a 3D model to your room.

Start by exploring the 3D models in Reality Composer Pro and learn how to import your own models. Then, create a volumetric window to view a 3D model. Before you go, add a drag gesture to rotate the model in 3D space.

## Overview

These resources are associated with the [Create 3D models in the Shared Space](https://developer.apple.com/tutorials/develop-in-swift/create-3d-models-in-the-shared-space) tutorial. This is part of the [Spatial Computing](https://developer.apple.com/tutorials/develop-in-swift/welcome-to-spatial-computing) tutorials from [Develop in Swift](https://developer.apple.com/tutorials/develop-in-swift) by Apple.

## Using theses resource

Follow the tutorial instructions in section one of [Create 3D models in the Shared Space](https://developer.apple.com/tutorials/develop-in-swift/create-3d-models-in-the-shared-space) to use these resources within the Xcode app.
