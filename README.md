## 📌 이 레포지토리의 목적

이 레포지토리는 Apple의 **visionOS 공식 튜토리얼**을 기반으로  
공간 컴퓨팅 앱 개발을 위한 기초 지식과 개발 역량을 쌓기 위한 저장소입니다.

단순히 튜토리얼을 따라하는 것이 아니라  
👉 **visionOS 앱의 구조와 동작 방식을 이해하고, 실제 구현 능력을 기르는 것**을 목표로 합니다.

- visionOS 앱 구조 이해
- SwiftUI 기반 UI 구성 방식 학습
- 공간 환경에서의 앱 동작 방식 이해
- 실제 프로젝트로 확장 가능한 개발 기반 구축

## 📌 Purpose of This Repository

This repository is based on Apple’s official **visionOS tutorials**,  
aiming to build fundamental knowledge and development skills for spatial computing applications.

Rather than simply following tutorials,  
👉 the goal is to **understand how visionOS apps are structured and operate, and to develop real implementation skills.**

- Understanding visionOS app architecture  
- Learning UI construction with SwiftUI  
- Exploring how apps behave in spatial environments  
- Building a foundation for real-world projects  

---

## 🎯 What I Focus On

- Understanding core UI structures in visionOS  
  → Window / Volume / Space  

- Building app structure and UI with SwiftUI  

- Understanding app lifecycle and data flow in visionOS  

- Comparing traditional 2D apps with spatial computing apps  

- Hands-on implementation based on Apple’s official tutorials
